# Bluetooth APTX HD transmitter with 3.5mm analog audio input

## Requirements
The product capabilities are listed below:
1. The device should be able to accept a 3.5mm audio connector with 2 channel analog audio.
2. The device should have a bluetooth audio chip that can send the audio to a speaker. The bluetooth must be easy to pair and must maintain a consistent pairing forever or until repaired. The speaker for example that will be paired with the device is [here](https://www.amazon.ca/JBL-Flip-Bluetooth-Waterproof-PartyBoost/dp/B09GJZKQ3K/ref=sr_1_7?crid=3MMM3X16T7RHI&keywords=jbl%2Bbluetooth&qid=1698858186&s=electronics&sprefix=jbl%2Bbluetooth%2Celectronics%2C87&sr=1-7&th=1).
3. Preference is a good Qualcomm APTX IC or equivalent Chinese variant.
4. Require a USB C connector for powering the device.
5. The overall device should be as small and cost effective as possible
